# 🖼️ Image Slider

A simple and responsive **Image Slider** built using **HTML, CSS, and JavaScript**. Users can navigate through images using **Previous** and **Next** buttons with a clean and modern UI.

## ⚙️ How It Works

1. Images are stored in an array.
2. JavaScript keeps track of the current image index.
3. Clicking the **Next** button displays the next image.
4. Clicking the **Previous** button displays the previous image.
5. When the last or first image is reached, the slider loops continuously.
